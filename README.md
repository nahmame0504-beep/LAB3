# Lab 3 — Pipelines Hugging Face pour la classification de textes

Ce projet présente la réalisation complète du **Lab 3**, axé sur l'utilisation et l'évaluation de pipelines pré-entraînés issus de la bibliothèque **Hugging Face `transformers`**.

L'objectif principal est d'explorer et d'expérimenter différentes tâches clés du traitement automatique du langage naturel (NLP) à travers un script d'inférence unifié (`nlp_pipeline.py`).
